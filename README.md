# Simulador interactivo 74HC4852

Simulación educativa de un multiplexor analógico 4:1, con selección S1/S0, habilitación activa en bajo, voltajes ajustables y monitor de señales.

## Publicación
1. Crea un repositorio público en GitHub llamado `simulador-74HC4852`.
2. Sube `index.html` a la raíz del repositorio.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/(root)` y guarda.
4. Abre `https://TU-USUARIO.github.io/simulador-74HC4852/`.

## Integración en Canvas
Inserta un iframe con la URL pública de GitHub Pages en el editor HTML de Canvas. El administrador de Canvas puede restringir dominios o iframes.

Modelo didáctico idealizado; no reemplaza una simulación eléctrica SPICE.
